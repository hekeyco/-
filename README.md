# 증강 알까기 — 웹 온라인 대전판

브라우저에서 바로 하는 증강 알까기입니다. 이 폴더를 서버에 올리면 주소 하나로 누구나 접속해 **코드로 방을 만들고 1대1 온라인 대전**을 할 수 있습니다. 로그인이나 초대는 필요 없습니다.

```
public/index.html   게임 화면 (규칙 계산도 전부 여기서 합니다)
server.js           게임 화면을 보여 주고, 같은 방 두 사람의 상태를 전달하는 서버
package.json        필요한 부품 목록 (ws 하나)
tests/smoke.js      빠른 점검 (npm test)
```

## 들어 있는 것

- 대국: 1대1(CPU가 기본, 같은 화면의 사람과도 가능), 온라인 1대1 · 지형 7종(평야, 흑요석 제단, 철옹성, 용오름, 연못, 차원, 반전)과 무작위 · 판 줄어듦 있음/없음 · 증강 45종(실버·골드·프리즘 각 15, 한 국 안에서 같은 증강은 다시 나오지 않음)
- 기객 5명(청운, 홍매, 백운, 솔하, 돌이)과 이름: 처음 접속하면 고르고, 첫 화면 맨 위에서 언제든 바꿀 수 있습니다. 겉모습과 이야기만 다르고 능력치는 같습니다. 초상은 배경이 있는 112px 도트 그림이며, 고르는 화면에서 가끔 눈을 깜빡입니다.
- 온라인 대전에서는 서로의 이름과 기객이 상대 화면에도 보입니다.
- 온라인 대전에서는 채팅으로 상대와 짧은 말을 주고받을 수 있습니다(한 번에 60자까지).
- CPU 난이도 쉬움·중간·어려움, 첫 화면 오른쪽 위 물음표 단추의 '조작 배우기'(움직이는 그림 5장면)
- 새 지형으로 국을 열면 지형 소개 그림이 잠깐 나옵니다(건너뛰기 가능). 국이 끝나면 결과 화면에서 다음 지형을 바꿀 수 있습니다.
- 온라인 대전의 국 시작 증강은 두 사람이 같은 때에 고릅니다.

## 어떻게 돌아가나요

- 방을 만든 사람이 흑, 다섯 글자 코드로 들어온 사람이 백입니다.
- 차례인 사람의 브라우저가 샷을 계산하고 결과를 서버로 보냅니다. 상대 브라우저는 같은 샷을 다시 재생한 뒤, 보낸 쪽의 결과로 맞춥니다.
- 서버는 방과 상태 전달만 맡습니다. 그래서 가볍고 무료 서버로도 충분합니다.
- 잠깐 연결이 끊기거나 서버가 다시 켜져도, 두 브라우저가 자기 상태를 다시 올려서 대국이 이어집니다.

## 1. 내 컴퓨터에서 먼저 해 보기

1. [Node.js](https://nodejs.org) 18 이상을 설치합니다.
2. 이 폴더에서 터미널을 열고 다음을 입력합니다.
   ```
   npm install
   npm start
   ```
3. 브라우저 창 두 개로 `http://localhost:3000` 을 엽니다. 한쪽에서 **온라인 1대1 → 방 만들기**, 다른 쪽에서 코드를 넣고 **입장**하면 됩니다.

같은 와이파이에 있는 친구는 `http://내컴퓨터IP:3000` 으로 들어올 수 있습니다 (방화벽에서 3000번 포트를 열어야 할 수 있습니다).

## 2. 인터넷에 올리기 (Render 무료 플랜 예시)

1. **GitHub에 올리기**
   - [github.com](https://github.com)에서 새 저장소(New repository)를 만듭니다. 비공개(Private)여도 됩니다.
   - 저장소 화면의 **Add file → Upload files** 에 이 폴더 안의 파일들(`public` 폴더, `tests` 폴더, `server.js`, `package.json`, `README.md`, `.gitignore`)을 끌어다 놓고 **Commit changes** 를 누릅니다. `node_modules` 폴더는 올리지 않습니다.
2. **Render에서 서버 만들기**
   - [render.com](https://render.com)에 GitHub 계정으로 가입합니다.
   - **New → Web Service** 를 누르고 방금 만든 저장소를 고릅니다.
   - 다음처럼 채웁니다.
     - Runtime: `Node`
     - Build Command: `npm install`
     - Start Command: `npm start`
     - Instance Type: `Free`
   - **Deploy** 를 누르고 1~3분 기다리면 `https://내서비스이름.onrender.com` 주소가 생깁니다.
3. **친구와 하기**
   - 그 주소를 친구에게 보냅니다. 내가 **방 만들기**를 누르고 나온 코드를 알려 주면, 친구가 코드를 넣고 들어옵니다.

### 무료 플랜에서 알아 둘 점

- 15분 동안 아무도 접속하지 않으면 서버가 잠듭니다. 잠든 뒤 첫 접속은 서버가 깨어나는 데 1분 정도 걸립니다. 게임 화면은 열리자마자 서버를 깨우기 시작하니, 메뉴를 고르는 동안 대부분 준비됩니다.
- 대국 중에는 게임이 주기적으로 신호를 보내 서버가 잠들지 않습니다.
- 무료 사용 시간은 한 달에 750시간입니다. 서버 하나를 한 달 내내 켜 두어도 들어가는 양입니다.

### 게임을 고친 뒤 다시 올리기

`public/index.html` 을 새 파일로 바꿔 GitHub에 다시 올리면, Render가 알아서 새 버전으로 다시 배포합니다.

## 다른 곳에 올리고 싶다면

- **Node를 돌릴 수 있는 곳이면 어디든** 됩니다 (Railway, Fly.io, Koyeb, 직접 빌린 서버 등). `npm install` 후 `npm start` 로 실행하고, 서버가 알려 주는 `PORT` 환경변수를 그대로 씁니다.
- 직접 nginx 뒤에 둔다면 `/ws` 경로에 WebSocket 업그레이드 설정(`Upgrade`, `Connection` 헤더 전달)이 필요합니다.
- GitHub Pages나 Netlify 같은 **정적 호스팅만으로는 온라인 대전이 되지 않습니다**. 방을 이어 주는 `server.js` 가 돌아가야 합니다.

## 한계

- 친구끼리 하는 용도로 만들었습니다. 계정이나 랭킹이 없고, 규칙 계산을 브라우저에서 하므로 작정하고 조작하는 사람을 막지는 못합니다.
- 방 코드를 아는 사람은 누구나 들어올 수 있습니다. 세 번째로 들어온 사람은 관전자가 됩니다.
- 채팅은 저장되지 않고, 걸러 주는 기능도 없습니다. 새로고침하면 지난 대화는 사라집니다.
- 서버를 다시 켜면 방 목록은 비워지지만, 이미 대국 중이던 두 사람은 자동으로 다시 연결되어 이어서 둘 수 있습니다.


## 온라인 순위표(전적)를 지워지지 않게 남기기

순위표 기록은 서버의 `data/matches.json` 파일에 저장됩니다. Render 무료 서버는 **새 버전을 올리거나(다시 배포) 오래 쉬었다 켜지면 이 파일이 지워집니다.**
버전을 올려도 전적이 그대로 남게 하려면 무료 Redis인 Upstash를 한 번만 연결해 두세요.

1. https://upstash.com 에 가입 → **Create Database**(Redis, 무료) 를 만듭니다.
2. 만든 데이터베이스의 **REST API** 칸에서 `UPSTASH_REDIS_REST_URL` 과 `UPSTASH_REDIS_REST_TOKEN` 값을 복사합니다.
3. Render 서비스의 **Environment** 메뉴에 위 두 이름 그대로 값을 넣고 저장합니다(자동으로 다시 시작됩니다).

이렇게 해 두면 그다음부터는 `public/index.html`이나 `server.js`를 새로 올려도 전적이 지워지지 않습니다.
(연결하기 전에 쌓인 기록은 이미 파일에만 있으므로, 연결 후 첫 재시작 때 사라질 수 있습니다.)

### v1.43 판 크기 고정, 방 코드 자동 복사

- **판 크기 고정**: 넓은 화면에서 오기·행복한 다람쥐·변화구처럼 판 위에 단추나 상태 줄이 생기는 증강을 얻어도 판이 작아지거나 움직이지 않습니다. 그 줄은 그 기객 칸 아래에 나옵니다.
- **차례 줄 오른쪽 정리**: 제한 시간이 없는 대국에서는 '진행 N수' 표시가 오른쪽 끝에 붙고, 조준 안내는 그 바로 아래에 나옵니다.
- **방 코드 자동 복사**: 온라인 1대1에서 '방 만들기'를 누르면 방 코드가 바로 복사됩니다. 상대에게 붙여 넣어 보내면 됩니다.
- 변화구를 가진 채로 화면을 그릴 때 나던 오류를 고쳤습니다.

### v1.42 기록·채팅 칸, 메뉴 정리, 돌 고르기

- **칸 줄 맞춤**: 넓은 화면에서 양옆 칸의 윗선은 차례 줄과, 아랫선은 판 테두리와 맞습니다. 판 테두리 좌우도 차례 줄 너비와 같습니다.
- **왼쪽 아래 대국 기록**: 예전처럼 기록 목록이 늘 보입니다. 판 위에 잠깐 뜨던 알림은 없앴습니다.
- **오른쪽 아래 채팅**: 온라인 대국에서 상대(관전자 포함)와 대화할 수 있습니다. 입력하고 Enter 또는 '보내기'. 1초에 한 마디까지 보내지고, 입력 중 ESC를 누르면 입력만 끝납니다. 온라인이 아닐 때는 칸만 보이고 입력은 막혀 있습니다(좁은 화면에서는 온라인일 때만 보입니다).
  - 서버는 바꿀 필요가 없습니다. 채팅은 방 상태에 마지막 한 마디를 실어 보내는 방식입니다.
- **머리줄**: 넓은 화면에서는 '소리', '메뉴' 순서로 두 단추만 보입니다.
- **ESC 메뉴**: 계속하기 · 증강 설명표 · 기권 · 새 대국 네 가지만 남겼습니다. 기권할 수 없는 때에는 기권 칸이 흐리게 보입니다. 규칙과 순위표는 첫 화면에서 봅니다.
- **돌 고르기**: '돌 잠금' 켜기·끄기를 없애고 예전 방식으로 고정했습니다. 내 돌을 누르면 그 돌이 골라지고(금빛 고리), 그다음에는 판 어디서든 끌어서 쏠 수 있습니다. 다른 내 돌을 누르면 그 돌로 바뀝니다.
- 순위표 창과 전적 저장 방식은 그대로입니다.

### v1.41 화면 손질 (PC·스팀용 한 화면)

가로가 넓은 화면(너비 960px 이상, 가로로 긴 창)에서만 바뀝니다. 휴대폰처럼 좁은 화면은 예전 배치 그대로입니다.

- **스크롤 없는 한 화면**: 창 크기에 맞춰 판 크기가 정해지고, 페이지가 위아래로 밀리지 않습니다.
- **판은 가운데, 기객은 양옆**: 내 기객은 왼쪽, 상대는 오른쪽에 큰 초상으로 마주 봅니다(온라인은 내 자리가 왼쪽). 차례인 쪽 칸이 빛나고, 남은 돌 수를 크게 보여 줍니다. 지형 정보는 상대 칸 아래에 있습니다.
- **판 위 알림**: 오른쪽에 쌓이던 대국 기록은 판 위에 잠깐 떴다 사라집니다. 전체 기록은 메뉴의 '대국 기록'에서 봅니다.
- **ESC 메뉴**: 머리줄의 단추들과 규칙·증강 설명표·순위표를 한곳에 모았습니다. 계속하기 · 소리 설정 · 돌 잠금 · 규칙 · 증강 설명표 · 온라인 순위표 · 대국 기록 · 기권 · 새 대국. 머리줄 오른쪽 '메뉴' 단추로도 엽니다.
  - CPU·같은 화면 대국은 메뉴를 연 동안 멈춥니다. 온라인 대국은 계속 흐릅니다.
  - 조준 중에 ESC를 누르면 조준이 취소됩니다.
- **브라우저 티 줄이기**: 글자 끌어 선택, 우클릭 메뉴, 그림 끌기가 막혔습니다. 넓은 화면에서는 Ctrl+휠·Ctrl+± 확대도 막습니다. 이름·방 코드 입력 칸은 그대로 선택됩니다.
- 첫 화면 안내 문구: "자세한 규칙은 '규칙'에서 볼 수 있습니다."로 바꿨습니다.
- 순위표 창과 전적 저장 방식은 그대로입니다.
